Version 0.2.0-pwa-firebase — 2026-11-06

Cubelyo est proposé par Christian Grohens. Jeu de logique 3D : faire tourner un cube pour libérer des flèches dont le trajet est dégagé.
Site : http://127.0.0.1:3107. Support : support@javachrist.fr. Les offres payantes, lorsqu’elles existent, relèvent également des CGV.

## Accès et public

Version locale destinée aux essais de Cubelyo. Le public admis et les éventuelles règles concernant les mineurs restent à définir pour la version publiée.

## Prérequis et fonctionnement

Navigateur récent avec JavaScript, stockage local et WebGL. Rotation à la souris ou au toucher ; pincement pour zoomer sur écran tactile. La compatibilité sur appareils réels reste à valider.

Le jeu est une version de test pouvant évoluer. Aucun engagement de disponibilité de production n’est défini à ce stade. La progression reste sur le navigateur utilisé.

## Compte

Une identité Firebase anonyme est créée pour la sauvegarde en ligne. Aucun nom, courriel ou mot de passe n’est demandé. Elle est conservée sur ce navigateur ou cette installation Android. Effacer les données de l’appareil ou changer d’appareil peut faire perdre l’accès à cette identité ; aucune liaison à un compte récupérable ni connexion entre appareils n’est encore proposée. Une connexion est nécessaire pour synchroniser. En cas de conflit, le joueur choisit la sauvegarde à conserver ; les soldes ne sont pas additionnés. Il peut désactiver la synchronisation dans les réglages sans effacer les données distantes.
